Core Features

不只是控制，更是原生与极致

告别每次打开手机 App 的繁琐操作。MiBar 以纯正的 macOS 设计语言与强悍的底层通信能力，重塑挂灯交互。

纯正 macOS 原生质感

针对 macOS Sonoma 与 Sequoia 深度打磨。常驻菜单栏，采用原生毛玻璃材质、自适应弹窗与丝滑弹性阻尼动画，轻巧无感。

局域网 miIO 秒级响应

基于 local UDP 加密握手直连挂灯（端口 54321）。毫秒级即时反馈，断网亦可在局域网内稳定控制，无需等待外网云端中转。

米家扫码一键配置

内置米家 OAuth 扫码登录。使用米家 App 或微信扫一扫即可自动检索名下设备，一键抓取 IP 与 32 位 Token，免去传统抓包困扰。

Keychain 硬件级安全隔离

设备 Token 与凭据使用 macOS 钥匙串（Keychain）安全隔离加密保存。不上传任何云端服务器，全程离线安全，隐私零泄漏。

胶囊微调与情景预设

1% ~ 100% 胶囊触控滑块，2700K 暖光到 6500K 冷光细腻渐变。内置专注、阅读、影音、休闲预设，轻轻一点一秒切换心仪光效。

现代 Swift 6 架构

纯 SwiftUI + Observation (`@Observable`) 构建，严格遵循 Swift Concurrency 线程安全。内存占用低于 15MB，超低能耗。

Quick Start

两步搞定，开启无感控灯

无论你是否了解米家局域网通信，MiBar 都提供了最简易的配对体验。

推荐方案
1

米家扫码一键配置

  • ① 启动 MiBar，点击菜单栏图标打开「设置」面板。
  • ② 点击「米家扫码登录」，使用手机米家 App 扫码授权。
  • ③ MiBar 将自动解析名下的显示器挂灯 1S，并自动填入 IP 与 Token。
  • ④ 点击保存，即可开始畅快调光！
2

手动填写 IP & Token

  • ① 若你已拥有抓包或网关获取的设备参数，可选择手动配置。
  • ② 设备 IP：填入路由器分配的 IPv4（如 192.168.1.100）。
  • ③ 设备 Token：填入 32 位 Hex 密匙字符串。
  • ④ 点击「保存并连接」即刻握手成功。

FAQ

常见问题解答

非常安全。MiBar 采用官方 OAuth 临时扫码会话，应用不会保存你的任何密码或账号信息。扫码仅用于获取局域网内挂灯设备的 IP 与通信 Token，获取后会话立即销毁，Token 仅保存在你的 macOS 本地 Keychain 中。
建议在路由器后台为挂灯设置「静态 DHCP 绑定」（固定 IP）。若未绑定且 IP 改变，只需重新在 MiBar 中扫码或在设置页面更新 IP 即可。
米家显示器挂灯一代为非智能无线 2.4GHz 旋钮控制，不具备 Wi-Fi 芯片与 miIO 协议支持。MiBar 专门支持米家智能显示器挂灯 1S（型号：yeelink.light.lamp22）。
在 macOS 14+ 下使用 Xcode 15/16 打开 MiBar.xcodeproj，设置构建目标为 My Mac，按 Cmd + R 即可一键编译运行。
