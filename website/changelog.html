v1.1.0 Latest
2026-09-02

✨ 视觉与交互体验升级

  • 快捷场景 Glass 拟态玻璃质感：预设按钮采用系统级 .ultraThinMaterial，通透轻盈。
  • 高光反光与多色渐变描边：增加顶部 Specular Highlight 真实玻璃反射与自适应渐变边缘。
  • 微交互优化：支持平滑 Hover 提亮与悬浮微缩放，选中时呈现场景主题色浸润；移除多余阴影保持纯净原生。

🔒 存储与权限体验优化

  • Token 存储无感化（UserDefaults 隔离存储）：避免非沙盒/本地构建环境下 Keychain 频繁弹出系统授权密码对话框的问题。
  • 实现零密码干扰、静默读取与秒级保存，大幅优化开箱即用体验。

🏗️ 架构与组件化解耦

  • 全面重构 LightMenuView，将单一 900 行视图解耦为 LightMenuHeaderView、SceneGlassButton、LightMenuFooterView 与 LightConfigurationView 等微组件。
  • 主视图精简至约 140 行，模块分工明确，大幅提升可维护性。
v1.0.0 2026-08-30

🚀 初始版本发布

  • macOS 原生菜单栏常驻：适配 macOS 14+ / 26+ 原生毛玻璃弹出窗口与自适应收缩。
  • 局域网 miIO 直连：基于 UDP 报文与 AES-128-CBC 加密，毫秒级极速调光。
  • 双维度平滑滑块：高精度支持 1%~100% 亮度与 2700K~6500K 色温调节，支持触控板与滚轮手势。
  • 四大快捷情景：一键切换夜间、休闲、阅读与专注模式。
  • 米家扫码快速导入：免抓包自动拉取挂灯 IP 与通信凭据。
